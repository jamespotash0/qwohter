# Qwohter - Professional Quote Management

## Project Overview

Qwohter is a professional quote management system built for businesses to create, manage, and track proposals efficiently.

## Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, shadcn/ui
- **State Management**: Zustand, TanStack Query
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Monitoring**: Sentry

## Development

### Prerequisites

- Node.js (v18+)
- npm

### Setup

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to project directory
cd wallqu-form-builder

# Install dependencies
npm install

# Start development server
npm run dev
```

### Available Scripts

```sh
npm run dev           # Start development server
npm run build         # Production build
npm run lint          # Run ESLint
npm run test          # Run tests
npm run test:coverage # Run tests with coverage
```

## Deployment

This project is deployed on Vercel. Push to the `main` branch to trigger automatic deployment.
