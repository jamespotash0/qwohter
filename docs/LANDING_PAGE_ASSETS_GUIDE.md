# 🎨 Landing Page Assets Guide

## Overview
This guide contains all the specifications and ChatGPT/DALL-E prompts needed to create stunning 3D mockup images for the WallQu landing page.

---

## 📐 Image Specifications

**Format**: PNG with transparent background (where applicable)
**Resolution**: 4K (3840 x 2160) or 2K (2560 x 1440) minimum
**Aspect Ratio**: 16:9 for feature images
**File Size**: Optimize to < 500KB per image
**Color Palette**:
- Primary Blue: `#3B82F6`
- Secondary Purple: `#8B5CF6`
- Accent Orange: `#F97316`
- Success Green: `#10B981`
- Background: White `#FFFFFF` / Light Gray `#F3F4F6`

## 🚀 Implementation Steps

1. **Generate Images in ChatGPT**:
   - Copy each prompt above
   - Paste into ChatGPT with DALL-E access
   - Download high-resolution images
   - Optimize with TinyPNG or ImageOptim

2. **Save to Project**:
   ```
   /public/images/landing/
   ├── hero-app-preview.png
   ├── feature-quote-generation.png
   ├── feature-template-editor.png
   ├── feature-analytics.png
   └── icons/
       ├── zap-3d.svg
       ├── palette-3d.svg
       ├── chart-3d.svg
       ├── building-3d.svg
       └── hammer-3d.svg
   ```

3. **Optimize Images**:
   ```bash
   # Using ImageMagick
   convert input.png -resize 1920x1080 -quality 85 output.png

   # Or use online tools
   - TinyPNG.com
   - Squoosh.app
   - ImageOptim (Mac)
   ```

4. **Update Landing.tsx**:
   - Replace placeholder divs with actual images
   - Add proper alt text
   - Implement lazy loading
   - Add blur-up effect for progressive loading
